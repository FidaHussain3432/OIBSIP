## 🚀 Project: Pizza Delivery Full-Stack Application

A production-grade pizza ordering and inventory management platform with:

- 👤 **User Side:** Registration, Login (JWT), Custom Pizza Builder, Razorpay Payment, Real-time Order Tracking
- 🔧 **Admin Side:** Separate Login, Inventory Dashboard, Auto Stock Decrement, Low-Stock Email Alerts, Order Management

### Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React.js |
| Backend | Node.js + Express.js |
| Database | MongoDB |
| Auth | JWT (JSON Web Tokens) |
| Payment | Razorpay (Test Mode) |
| Email | Nodemailer |
| Scheduled Jobs | Node-cron |
| Real-time | Socket.io |
