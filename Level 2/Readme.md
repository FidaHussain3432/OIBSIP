## 🌟 Overview

Level 2 is the **intermediate tier** of the Web Development & Design track. It consists of **4 tasks** that must **all be completed** — Level 2 completion is all-or-nothing.

Each task is self-contained and builds a different skill:

| Task | Skill Focus |
|------|-------------|
| **1. Calculator** | State management · Custom arithmetic logic · Event handling |
| **2. Tribute Page** | Layout design · Typography · Content presentation |
| **3. To-Do Web App** | CRUD operations · DOM manipulation · LocalStorage persistence |
| **4. Login Authentication System** | Form validation · Hashing · Session management |

## 🎯 Skills Covered

### Task 1 — Calculator
- Custom arithmetic engine (no `eval()`)
- Three-state model (currentInput, previousValue, currentOperator)
- Event delegation and `addEventListener`
- CSS Grid for keypad layout
- Floating-point precision handling
- Semantic HTML5 (`<output>`, `<section>`, `<button>`)

### Task 2 — Tribute Page *(planned)*
- Responsive layout design
- Typography pairing (Google Fonts)
- Content hierarchy and visual storytelling
- Timeline/list design

### Task 3 — To-Do Web App *(planned)*
- CRUD operations with DOM
- LocalStorage persistence
- Inline editing
- Empty state UX

### Task 4 — Login Authentication System *(planned)*
- Form validation
- SHA-256 password hashing (Web Crypto API)
- Session management via localStorage
- Protected route redirection
